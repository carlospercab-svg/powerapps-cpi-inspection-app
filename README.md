# Fire Safety Inspection App (Power Apps)

## 📊 Overview
This project consists of a mobile application developed using Microsoft Power Apps to digitize the inspection process of fire safety equipment in a hospitality environment.

The solution allows technicians to perform real-time inspections directly from their mobile devices, automatically recording results in a centralized Excel database.

---

## 🚀 Problem Solved
Previously, fire safety inspections were conducted manually using paper checklists. After completing the inspections, data had to be manually transcribed into Excel files, creating a time-consuming and error-prone process.

---

## 💡 Solution
A Power Apps mobile application was developed to:

- Access a database of over 600 fire safety equipment items
- Guide technicians through standardized inspection checklists
- Record inspection results in real time
- Automatically store data in structured Excel tables
- Enable visual reporting and tracking

---

## ⏱ Impact
The implementation of this solution significantly improved operational efficiency, saving approximately:

**➡️ 45+ hours of manual work per month**

and eliminating manual data entry processes.

---

## 🛠 Tools Used
- Microsoft Power Apps
- Excel Database (Structured Tables)
- Process Digitalization
- Mobile Inspection Workflows
